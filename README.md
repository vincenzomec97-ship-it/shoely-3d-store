# Shoely — 3D Sneaker Store

Configurazione iniziale di una landing page e-commerce 3D realizzata con React, Vite e Three.js.

## Requisiti

- Node.js compatibile con la versione di Vite installata
- npm

## Comandi

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Struttura

- `src/`: applicazione React
- `public/images/`: immagini pubbliche
- `public/models/`: modelli 3D
- `references/`: riferimenti di progetto, esclusi dal prodotto finale

La scena 3D e l'interfaccia e-commerce verranno sviluppate nelle fasi successive.
